# Single Agent Quickstart

This is a minimal example of running a **single agent** in a Grid2Op environment.

## Environment

- `l2rpn_case14_sandbox` – small and included by default in Grid2Op

## Agent

- `RandomAgent` – chooses actions randomly
- This is a simple baseline, not trained
- Results may be unstable (powerflow errors can happen)

## Requirements

`pip install grid2op`
